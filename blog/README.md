# ZotSeek-U Blog

This directory is reserved for the ZotSeek-U project blog.

The blog will document project direction, retrieval experiments, design decisions,
release notes, and development notes. Blog source content and images will be kept
in this directory and may later be published as a static site through GitHub Pages.

The public project tagline is currently:

> Universal, multilingual, and evidence-grounded retrieval for Zotero.

The GitHub Pages publishing workflow is not configured yet. See the external
workspace plan for the proposed publishing structure and future implementation
steps.
